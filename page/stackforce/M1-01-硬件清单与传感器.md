## M1.2 跑通传感器（只读，不控制）

这是最安全的第一项实机实验。目标是得到：

```python
state = robot.read_state()
# state = {"imu": ..., "joint_pos": ..., "joint_vel": ..., "wheel_vel": ...}
```

然后**手动操作机器人，验证每个信号的物理意义**。记录表（以后价值非常大）：

| 动作 | Sensor 变化 |
|------|-------------|
| 向前倾 10° | pitch = ? |
| 向后倾 10° | pitch = ? |
| 向左倾 | roll = ? |
| 向右倾 | roll = ? |
| FL 腿向前 | q_FL_hip ↑ / ↓ ? |
| FL 膝关节弯曲 | q_FL_knee ↑ / ↓ ? |
| FL 轮向前滚 | ω_FL ↑ / ↓ ? |
| FR 轮向前滚 | ω_FR ↑ / ↓ ? |

你真正要确定的是：

```text
正方向（boxed）
```

## M1-1 源码基线结论（已确认）

对官方整机工程做静态分析，以下为 **CONFIRMED** 事实（其余仍 UNKNOWN）：

| 项目 | 结论 | 状态 |
|------|------|------|
| 主控 | ESP32-S3 DevKitC-1（两块：Device 0x01 / 0x02） | CONFIRMED |
| 框架 | Arduino / PlatformIO，espressif32@6.6.0 | CONFIRMED |
| 调试串口 | 115200 baud | CONFIRMED |

数据流：

```text
PPM(GPIO40) → Device 0x01 → I2C(SDA1/SCL2,400k) → PCA9685@0x40(8舵机) + MPU6050
                           → Serial2 → 后轮双路 BLDC
                           → CAN 1Mbps extended → Device 0x02 → Serial2 → 前轮双路 BLDC
```

总线与引脚（除标注外均为 CONFIRMED）：

| 接口 | 参数 | 用途 | 状态 |
|------|------|------|------|
| I2C / Wire | SDA GPIO1, SCL GPIO2, 400 kHz | PCA9685、MPU6050 | CONFIRMED |
| CAN / TWAI | TX GPIO35, RX GPIO41 | Device 0x01 ↔ 0x02 | CONFIRMED |
| CAN bitrate | 1 Mbit/s | 控制器间通信 | CONFIRMED |
| CAN frame | Extended / 29-bit（`setMode(1)`） | 控制器间通信 | CONFIRMED |
| PPM | GPIO40 | 遥控器输入 | CONFIRMED |
| Debug Serial | 115200 baud | 调试输出/参数输入 | CONFIRMED |
| Serial2 | BLDC 库使用 | 双路无刷电机控制板 | CONFIRMED |
| Serial2 baud/pins | — | — | UNKNOWN |

传感器已确认：

- **IMU MPU6050**（I2C）：姿态 `pitch=getAngleX()+pitch_off(2)`、`roll=-getAngleY()+roll_off(-1)`、`yaw=getAngleZ()`；陀螺仪 API `getGyroX/Y/Z()`；加速度未用于整机控制；单位/更新率/安装旋转仍 UNKNOWN。
- **BLDC 反馈** `SF_BLDC_DATA`：Angle/ElecAngle/Vel/Uq/Ud/Iq/Id，主程序只用了 M0_Vel / M1_Vel。底层 `SF_Motor` API 声明（后续验证线索）：`getAnlge()` 角度单位 rad、`getVelocity()` 速度注释"单位 rad"（应实机核实具体为 rad/s）、`getCurrent()` 电流注释 mA。
- **舵机无反馈**：`SF_Servo` 只有 PWM 命令，无 position/velocity 反馈 API → Actor 观测不能默认依赖腿关节真实 encoder。
- **遥控 PPM**：GPIO40，8 通道，sync gap 3000μs；源码注释主要用途 CH1 左右转向、CH2 前进/后退、CH3 腿高、CH4 roll，其他通道用于速度/模式切换。

控制职责：Device 0x01 负责 PPM 解析 / IMU / 8 舵机 / 后轮双路 BLDC / 稳定 / 逆运动学 / 算前轮目标发 CAN；Device 0x02 收 CAN ID 0x02 的 8 字节命令并送给前轮双路 BLDC。

上位机实时控制接口：当前尚未确认（暂无正式 PC→机器人 state/action 协议），见 [[M1-03-控制接口与频率延迟]]。

未确认项与验证计划（两块 ESP32 精确安装位置、Serial2 引脚/波特率、主循环周期、Device 0x02 回传被注释等）见 [[M1-05-硬件API与安全]]。
