# M2-02-机械结构审核

> 本页属于：stackforce 机器狗实战（M2 资产检查）
> 前置知识：[[M2-01-资产来源与版本]]
> 预计阅读时间：20 分钟

## 🎯 为什么需要这个？

资产拓扑必须和真实机器人一致。此前已确认：每条轮足是**双支链闭环**，不是 Mini 式单串联链。本页用这份独立结论审核 sf_robot。

## 已确认的真实结构（审核基线）

```text
base
├─ hip_M(active) ─ thigh_M ─ elbow_M(passive) ─ lower_M ─ wheel_motor(active) ─┐
│                                                                                ├─ wheel
└─ hip_S(active) ─ thigh_S ─ elbow_S(passive) ─ lower_S ─ wheel_support(passive)┘
```

- `M = motor-side = inner branch`，`S = support-side = outer branch`（CONFIRMED_BY_ASSEMBLY）
- 每条轮足：**5 个运动刚体、6 个转动连接、3 个独立控制量**
- 整机：**4 个机械闭环、12 个独立控制量**（8 腿舵机 + 4 轮电机）
- 两个 elbow 是被动转轴；`wheel_motor` 是主动轮轴；`wheel_support` 是另一侧被动同轴支承
- 两侧必须最终对应**同一根物理 wheel axis**

## 审核要点（对照 sf_robot）

- link list / joint list
- active / passive 分类
- 是否表达每腿真实双支链闭环
- M/S branch 是否区分
- wheel motor / wheel support
- DOF / control dimension（应为 12）
- 与 `mechanical_model.md` 对照

## 明确不得做的事

- 不得把四轮足建成 Mini 式 `body → upper → lower → wheel` 单支链
- 不得把"2 个腿关节 + 1 个轮关节"当作 3 个串联关节（实际是闭环 + 被动肘）
- 不得未经审核就沿用 Mini URDF 的 joint tree
