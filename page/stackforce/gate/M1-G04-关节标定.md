## Known Facts

Real-side 机械坐标、零位定义、正方向定义、线性标定模型、轮子正方向和低风险多点标定流程已经完成静态定义。源码中的 `servo_off` 是驱动偏置，不等于真实机械零位；PCA9685 0–300° 也不等于关节限位。

Servo API 坐标为 degree-valued input，实际命令为 `u + servo_off[i]`；本机 offset 已冻结为 `[-4,-5,+5,-7,-3,-5,-8,+8] deg`。offset 不是 URDF zero，0–300 deg API guard 也不是机械安全范围。ch7 物理回中失败使当前装配/标定不可接受。
