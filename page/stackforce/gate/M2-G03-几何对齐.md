# M2-G03 几何对齐

## Goal

证明四腿闭链资产的关键尺寸、装配变换、网格绕向和轮轴同轴共线几何满足机器可读的严格设计公差。

---

## Known Facts

- 真实机构杆长标称值：大腿 M1-P1 / M2-P2 为 `60.000 mm`，小腿 P1-W1 / P2-W2 为 `100.000 mm`，两 hip 间距投影为 `40.000 mm`。
- $W_1$ 与 $W_2$ 存在沿公共机械轴向约 $-44.950\text{ mm}$ 的物理装配厚度错位，径向投影残差在 `four_inner_chains_validation.json` 中判定为 $1.83 \times 10^{-14}\text{ mm}$（小于 $2 \times 10^{-6}\text{ m}$ 门禁）。
- P2 膝部枢轴表面配合间隙实测为 $0.150\text{ mm}$，保证小腿摆动不发生刚性自干涉。
- 四腿网格基于 FR 主模板经底盘反射生成，FL 与 RR 经单平面镜像（$\det = -1$）后三角形顶点绕向（face winding）已严格反转，法线朝向一致。
