# M1-G05 指令定性

## Goal

确认每类执行器实际接受的 command 语义、单位和缩放。

## Why

变量名或协议范围不能替代真实 position、velocity、torque 语义。

- [[M1-T02-执行器映射]]

## Known Facts

腿部为 PCA9685 PWM position command；轮部程序调用 mode 4，即 `TORQUE_MODE`；CAN `[-100,100]` 仅为协议编码范围。
