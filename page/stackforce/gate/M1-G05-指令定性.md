# M1-G05 指令定性

## Goal

确认每类执行器实际接受的 command 语义、单位和缩放。

## Why

变量名或协议范围不能替代真实 position、velocity、torque 语义。

- [[M1-T02-执行器映射]]
- [[M1-T04-控制时序]]

## Known Facts

Servo 是 degree-valued position-style PWM command，offset 在 call site 相加，无 measured q/dq/current。Wheel 使用 mode 4 `TORQUE_MODE`；header 将 torque target 标为 A，但预编译 transport 的端到端 SI scaling 未标定。CAN `[-100,100]` 是编码范围，不是物理安全范围。架空实测已证明小 wheel target 可产生可控运动并归零。
