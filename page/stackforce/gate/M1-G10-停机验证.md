# M1-G10 停机验证

Milestone: M1 Real Hardware Baseline
Gate: G10
Status: **BLOCKED — KNOWN CHANNEL 7 PHYSICAL RETURN FAILURE**

## Gate 目标

冻结 power-on、zero command、input/CAN loss、normal/emergency stop、diagnostic timeout 与 baseline restore 的安全合同。

## 当前安全合同

| Condition | Current behavior | Evidence class |
|---|---|---|
| S1 boot | alignment 后两个 motor torque target 归零 | `SOURCE CODE` |
| S3 boot | local wheel target 归零；standing IK；gyro calibration | `SOURCE CODE` |
| PPM stale >100 ms | rear local 与 front remote target 归零 | `SOURCE CODE` |
| Device02 CAN stale >100 ms | front target 归零 | `SOURCE CODE` |
| Normal wheel stop | target 0 | `SOURCE CODE + HARDWARE MEASURED` |
| Servo enable | GPIO42 HIGH enable、LOW disable | `SOURCE CODE` |
| Emergency stop | 机器人电源开关/断电，多次成功使用 | `HARDWARE MEASURED` |
| Unified diagnostic | default zero、显式 ARM、单执行器、5 deg/0.5 限幅、command timeout、30 s ARM timeout、STOP | `SOURCE CODE + BUILD/RUNTIME VERIFIED` |

旧静态审计中的 `flat=1` 与 Device02 stale-buffer 风险不再适用于 current source：当前 normal firmware 使用 `flat=0`，PPM 与 CAN 均具有 100 ms freshness zeroing。不得继续把旧 snapshot 的风险写成当前行为。

## Runtime 结果

2026-09-10 两次架空 session 验证了 stable boot、wheel self-test 后停止、default-zero、single-command、command timeout、30 s ARM timeout、`STOP,operator` acknowledgement 和 normal baseline restore。

completion session 中，ch7 在 firmware 已发出回参考命令与显式 STOP 后仍持续上抬；ch8 可能受闭链被动带动。操作者立即断电并停止后续测试。该现象是 hardware/mechanical safety failure，优先级高于软件 STOP 成功记录。

## Blocker 与禁止事项

- 隔离检查 ch7/ch8，完成无负载 tiny return test；按结果维修或更换。
- 修复后再完成装配状态 tiny return test 和剩余 polarity registration。
- blocker 关闭前，actuator rail 必须保持断电；禁止真机 RL、落地 locomotion 或扩大动作范围。

## Evidence Debt

- 预编译 `SF_BLDC` 内部 Serial2 timeout 不可见。
- exact mechanical stopping distance 与精确 onset 未测。
- 危险的 CAN/PPM/Serial2 拔线 fault injection 不属于当前 M1 必做项。

## Acceptance Criteria

- [x] current-source boot、freshness、timeout 与 STOP contract 已冻结。
- [x] normal baseline restore 与代表性 automatic stop 已验证。
- [ ] ch7/ch8 修复后通过无负载和装配状态回中测试。

## Gate 结论

**BLOCKED。**正常 baseline 已恢复且 actuator power 已关闭；在 ch7/ch8 隔离、修复并通过回中测试前，不得重新给 actuator rail 上电或进行整机运动。
