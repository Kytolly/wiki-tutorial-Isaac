# M1-G08 尺寸测量

Milestone: M1 Real Hardware Baseline
Gate: G08
Status: **PASS WITH GEOMETRY PRECISION EVIDENCE DEBT**

## 当前进度

官方安装资料、实机多视角观察、firmware IK、URDF 与 STL 已交叉确认真实 five-bar moving-body graph 和共同 wheel closure。`60/100/100/60/40 mm` 名义平面几何足以构建首版 kinematic Reference-B；装配级精密测量仍未完成。

## 1. Gate 目标

建立 Nominal Geometry ↔ Real Measurement contract，统一 mm 与 m，并保留不同来源的语义差异。

## 2. Topics

wheel diameter/radius、wheel width、wheelbase、track width、body envelope、hip spacing、60/100 mm link lengths、root joint centers、wheel center 和 ground height。

## 4. Dimension Contract

每个 ID 的实测表必须包含：定义、静态值、来源、方法、实测值、差值、容差、状态、姿态和工具。URDF、STL、firmware 若不一致，分别列出并解释，禁止平均。

## 5. Real Measurement Checklist

轮径/轮宽、前后 hip 中心距、左右 hip 中心距、四条 60/100 mm 支链、根轴/轮轴平行度、body L/W/H、名义 ground height；每项至少三次，记录量具精度和测量姿态。

## Remaining Evidence Debt

- exact root xyz/rpy、装配误差与轴线偏差属于 higher-fidelity debt。
- 名义/mesh-derived 数据不能冒充 assembled metrology。

## 6. Runtime / Physical Validation Plan

断电、拆除可动负载后测量；先建立 robot base reference，再测轴线和轮中心。不要用图片比例或 STL volume 替代量具读数。

## 7. Acceptance Criteria

- Static: nominal dimension table 完整且来源分类正确。
- Physical: moving-body graph、branch naming、共同 wheel closure 已由实物观察支持。
- Deferred: 精确装配 transform 不阻塞 first kinematic Reference-B。

## 8. Gate 结论

**PASS WITH GEOMETRY PRECISION EVIDENCE DEBT。**
