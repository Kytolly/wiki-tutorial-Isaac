# M1-G06 控制测频

Milestone: M1 Real Hardware Baseline
Gate: G06
Status: **PASS WITH EVIDENCE DEBT**

## 当前进度

静态调度结构已冻结，IMU update-call timing 已实测为 mean 5.704 ms / 175.3 Hz、jitter 0.790 ms、min/max 3.331/9.181 ms。整机主循环仍不能宣称为固定 Hz；Device01 的 CAN 发送有 1 ms 软件门限，但这不是完整控制频率。

## 1. Gate 目标

建立控制、传感器、总线和执行器更新路径的真实频率与 jitter contract，区分 bus bitrate、sensor internal rate、software update rate、actuator PWM rate 和 control rate。

## 2. Topics

Device01/02 `loop()`、IMU update、PPM ISR、gait/IK/stabilization、PCA9685、CAN TX/RX、Serial2 BLDC telemetry/command。

## 4. Frequency Contract

静态可冻结的是调度形式和名义门限。真机必须分别测量 `ppm_isr`、`imu_update`、`control_loop`、`ik`、`servo_write`、`can_tx`、`can_rx`、`bldc_write`、`feedback_read` 和 stabilization update。未设固定周期的路径记录为 `UNTHROTTLED / AS-FAST-AS-POSSIBLE`，不填写猜测 Hz。

## 5. Instrumentation Plan

增加独立、默认关闭的 `M1_G06_TIMING_INSTRUMENTATION`：使用 `micros()` 累加 count、周期、min/max，按 0.5–1 s 窗口输出 mean period、mean Hz 和 jitter。禁止每 cycle `Serial.print()`，并与 G07/G10 共享缓冲与输出机制。

## Remaining Evidence Debt

- Device02 BLDC-write rate、Serial2 packet cadence 与 PPM receiver rate 仍未测。
- 部署必须显式选择低于传感器能力的 policy/action-hold rate，不能把 loop 或 CAN bitrate 当作 controller rate。

## 6. Runtime / Physical Validation Plan

轮体架空、默认关闭高频打印；先只读启动，再测 IMU/PPM、Device01 loop、CAN TX/RX、Serial2 BLDC 和 servo I2C。每项至少 10 s，冷启动重复三次。

## 7. Acceptance Criteria

- Static: 每条路径有 source、scheduler、名义 timing 和 evidence class。
- Runtime: 最小 Sim2Real timing contract 已具备。
- Deferred: 非关键路径精确频率留作部署阶段证据债务。

## 8. Gate 结论

**PASS WITH EVIDENCE DEBT。**
