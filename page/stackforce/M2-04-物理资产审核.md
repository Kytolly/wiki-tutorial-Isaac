# M2-04-物理资产审核

> 本页属于：stackforce 机器狗实战（M2 资产检查）
> 前置知识：[[M2-03-几何审核]]
> 预计阅读时间：20 分钟

## 🎯 为什么需要这个？

几何对了还要看物理：质量、惯量、碰撞、关节限位、摩擦、驱动，以及闭环如何表达。**这些大多仍为 M1_REQUIRED。**

## 审核清单

| 项 | 当前状态 |
|----|----------|
| mass（整机/各腿/轮/body） | M1_REQUIRED（实测） |
| inertia / COM | M1_REQUIRED（CAD + 实测校正） |
| collision（简化几何 vs 复杂 mesh） | 待审核 |
| joint limits（舵机真实机械限位） | M1_REQUIRED |
| damping / friction | M1_REQUIRED |
| drive / actuator（舵机 vs 轮电机） | 待审核（舵机=位置命令；轮=TORQUE_MODE 待确认） |
| closed-loop representation | 待审核 sf_robot 如何表达闭环 |
| articulation | 待审核 |

## 重要约束

- 标准 URDF 是树，真实轮足含机械闭环。**必须先检查 sf_robot 到底如何表达闭环**，而不是默认沿用旧的"wheel_support 断环 + USD/PhysX 恢复"方案（该方案现为 HISTORICAL DESIGN CANDIDATE，见 [[M2-reverse-engineering]]）。
- 质量/惯量不猜；实测重量 + CAD 惯量按质量比例校正（`I_corrected ≈ I_CAD × m_real / m_CAD`）。
