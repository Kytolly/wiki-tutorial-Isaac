# M3-动力学对齐

> 本页属于：stackforce 机器狗实战

## 🎯 为什么需要这个？

URDF 有了之后，**先不要碰 RL**。仿真和实机动力学差多少，必须先量化。M3 目标：**step response 基本吻合**，让 `Dynamics_sim ≈ Dynamics_real`。

## 💡 一个类比

这是"台架标定"：同一脚油门（输入），看真车和模拟器的速度曲线（输出）是否重合；不重合就调参数，直到两条曲线基本叠上。

## Joint step response 实验

实机给一个阶跃目标：

```text
q_d : 0 → 0.3 rad
```

记录 `q(t)`；仿真做**完全相同输入**，对比：

```text
 q
 │              real
 │           ╭────────
 │        ╭──╯
 │     ╭──╯       sim
 │   ╭─╯       ╭──────
 │ ╭─╯      ╭──╯
 └────────────────────── t
```

## 调哪些参数

```text
Kp  Kd  damping  friction  armature  motor strength
```

轮子也做同样实验：

```text
ω_d : 0 → ω
```

最终希望：

```text
Dynamics_sim ≈ Dynamics_real
```

## ✏️ 小练习

**1.** 为什么"先对齐、后 RL"？

<details>
<summary>查看答案</summary>

RL 依赖仿真梯度；如果动力学不匹配，仿真里学到的策略到实机就失效。先对齐能把 sim2real 差距压缩到最小。
</details>

**2.** step response 主要看曲线的什么？

<details>
<summary>查看答案</summary>

看响应速度、超调、稳态误差——反映 Kp/Kd/damping/friction 等参数是否和实机一致。
</details>

## 本章小结

- 做标准实验：joint step response、wheel step response。
- 同一输入对比 q(t)/ω(t)，调 Kp/Kd/damping/friction/armature/motor strength。
- 目标是 Dynamics_sim ≈ Dynamics_real。
