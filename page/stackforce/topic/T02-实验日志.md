## 1. 实验日志建设准则（First-Day Logging Principle）

在机器人项目开发的第一天就必须建立标准化的时序数据记录系统（Logger）。后续动力学校准（M3 Dynamics Calibration）、系统辨识（System Identification, SysID）以及 Sim-to-Real 部署排障，完全依赖高精度、不可篡改的逐周期真实数据。

---

## 2. 标准 CSV 日志表头与字段规范（CSV Logger Schema）

每个控制循环周期（$\Delta t = 0.01\text{ s}$）必须持久化写入一行格式化数据，表头严格采用 Canonical Terminology 形式：

```csv
timestamp,loop_dt,roll,pitch,yaw,gyro_x,gyro_y,gyro_z,FL_Outer_Hip_cmd,FL_Inner_Hip_cmd,FL_Wheel_cmd,FR_Outer_Hip_cmd,FR_Inner_Hip_cmd,FR_Wheel_cmd,RL_Outer_Hip_cmd,RL_Inner_Hip_cmd,RL_Wheel_cmd,RR_Outer_Hip_cmd,RR_Inner_Hip_cmd,RR_Wheel_cmd,RL_Wheel_vel,RR_Wheel_vel,battery_v,safety_flags
```

### 字段数据规范与量纲约束
1. **时间基准**：
   - `timestamp`：高精度单调时钟时间戳（Monotonic Time，微秒或毫秒精度）；
   - `loop_dt`：实际循环周期（秒），用于监测主循环 Jitter 与时钟抖动（`_meta/omissions.yaml: DEBT-U11`）。
2. **机身惯导姿态**：
   - `roll, pitch, yaw`：以度（deg）为单位，遵循 `E-FW-001#P04` 偏置校正公式；
   - `gyro_x, gyro_y, gyro_z`：三轴角速度，单位为 deg/s。
3. **执行器指令向量（12 DOFs）**：
   - 8 个腿部舵机指令（`*_Outer_Hip_cmd`, `*_Inner_Hip_cmd`）：开环目标角度，单位为 rad；
   - 4 个轮电机指令（`*_Wheel_cmd`）：Mode 4 力矩定点数指令，取值范围 `[-100, 100]`。
4. **状态反馈与安全标志**：
   - `RL_Wheel_vel, RR_Wheel_vel`：实测后轮线速度/角速度；
   - `battery_v`：动力电池母线电压（V），监控压降对电机力矩输出的影响；
   - `safety_flags`：安全层状态码（0=NORMAL, 1=CLAMPED, 2=TIMEOUT_WATCHDOG, 3=ESTOP）。

## 3. 证据追溯与可复现性绑定

任何正式提交至知识库的实验结论，必须在文档中显式绑定：
- 对应的日志相对路径（如 `logs/m1_session_20260910.csv`）；
- 测试时的代码 Git Commit 哈希；
- 执行命令与测试环境硬件连接描述。
