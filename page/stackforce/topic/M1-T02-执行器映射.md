# M1-T02 执行器映射

## Scope

建立软件 actuator、实体执行器和统一 joint name 的唯一映射。hip/knee 语义、零位、正方向和真实限位在实机确认前不提前命名或填值。

## 统一命名

```python
JOINT_NAMES = [
    "FL_hip", "FL_knee", "FL_wheel",
    "FR_hip", "FR_knee", "FR_wheel",
    "RL_hip", "RL_knee", "RL_wheel",
    "RR_hip", "RR_knee", "RR_wheel",
]
```

## 舵机基线

| 源码位置 | PCA9685 channel | 源码变量 | `servo_off` | 物理语义 |
|---|---:|---|---:|---|
| 左前腿-前舵机 | 3 | `servoLeftFront` | -5° | UNKNOWN |
| 左前腿-后舵机 | 4 | `servoLeftRear` | -7° | UNKNOWN |
| 右前腿-前舵机 | 2 | `servoRightFront` | +5° | UNKNOWN |
| 右前腿-后舵机 | 1 | `servoRightRear` | +3° | UNKNOWN |
| 右后腿-后舵机 | 7 | `servoBackLeftFront` | -8° | UNKNOWN |
| 右后腿-前舵机 | 8 | `servoBackLeftRear` | +8° | UNKNOWN |
| 左后腿-后舵机 | 6 | `servoBackRightFront` | -5° | UNKNOWN |
| 左后腿-前舵机 | 5 | `servoBackRightRear` | +3° | UNKNOWN |

驱动器为 PCA9685 `0x40`，PWM 50 Hz，API 范围 0–300°，脉宽 500–2500 μs，使能 GPIO42。API 范围不等于真实关节限位；源码没有舵机位置反馈 API。

## 轮电机基线

| 物理轮 | 逻辑电机/控制器 | command sign | feedback sign |
|---|---|---:|---:|
| 左后轮 | M0 / Device `0x01` | +1 | +1 |
| 右后轮 | M1 / Device `0x01` | -1 | -1 |
| 左前轮 | CAN target2 / Device `0x02` | +1 (`M3Dir`) | UNKNOWN |
| 右前轮 | CAN target1 / Device `0x02` | -1 (`M4Dir`) | UNKNOWN |

主程序和 Device `0x02` 均调用 `motors.setModes(4, 4)`；同一资料包的 `SF_Motor.h` 将 mode 4 定义为 `TORQUE_MODE`。

## 实机实验

架起机器人、四轮离地，一次只使能一个执行器，记录 `q_d = q_0 ± 0.05 rad` 的物理运动。每一行要同时记录硬件 ID、关节名、方向、零位和安全限位，再回填 `sf_quad` 的 joint order。
