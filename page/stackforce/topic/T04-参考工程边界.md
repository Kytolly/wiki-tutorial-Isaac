# T04 参考工程边界

## Scope

规定 `Stackforce-simready-111-isaac-lab` 与当前项目的关系。

## 使用方式

参考工程可以提供 Isaac Lab 工程组织、Environment、RL 配置、SimReady 工作流和 API 用法。它是 read-only reference，不是 `sf_quad` 的代码真源。

## 证据边界

- 参考工程日志只能证明参考工程的运行情况。
- 参考工程的资产、训练 checkpoint 或命名不能直接证明 StackForce 实机 Ground Truth。
- `sf_quad` 的代码、运行日志和实机测量必须分别作为当前项目证据。
- 参考工程若出现环境、显示或依赖错误，应在证据中保留错误状态，不把“命令已启动”写成 PASS。
