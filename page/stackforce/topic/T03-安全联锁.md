# T03 安全联锁

## Scope

定义独立于策略的保护、停机和恢复行为。

## 必须覆盖

```text
emergency stop
joint position/velocity/current limit
body tilt limit
communication timeout
policy timeout
NaN/Inf rejection
motor disable
safe state recovery
```

## 触发原则

任何触发条件都应停止或限制执行器输出，并记录触发原因和恢复动作。RL 不能关闭、绕过或覆盖安全联锁。

## 验证方法

在架空、保护架和低动作限幅条件下分别触发人工急停、断链、超时、异常值和姿态超限，记录停止延迟与最终执行器状态。未有实机记录前，安全系统只能标 TODO。
