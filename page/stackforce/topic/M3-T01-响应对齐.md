# M3-T01 响应对齐

## Scope

规定 Sim/Real 同输入实验、参数调整和响应误差报告的方法。M3 不负责证明策略能走路。

## 实验输入

关节阶跃示例：

```text
q_d: 0 → 0.3 rad
```

轮子使用同一版本的轮部 command 做阶跃。实机和仿真必须使用相同输入、采样窗口、初始姿态和安全限幅。

## 观测输出

记录 `q(t)`、`dq(t)`、`ω(t)`、稳态误差、响应时间、超调、延迟和失败原因。对比报告必须保留原始数据，不只保留曲线截图。

## 待校准参数

```text
Kp, Kd, damping, friction, armature, motor strength,
command scale, latency, wheel-ground friction, mass, COM, inertia
```

参数调整要说明数据来源和影响范围；不能用 M1 尚未测量的值冒充 calibrated value。

## PASS 依据

响应误差阈值应在实验前冻结，并按关节、轮子和整机分别报告。只有所有关键响应达到阈值，M3-G06 才能 PASS。
