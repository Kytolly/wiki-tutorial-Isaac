# M2-T02 机械拓扑

## Scope

把真实轮足的刚体、主动/被动关节和闭环关系表达为可审核的数字结构。

## 真实机构基线

```text
base
├─ hip_M(active) ─ thigh_M ─ elbow_M(passive) ─ lower_M ─ wheel_motor(active) ─┐
│                                                                               ├─ wheel
└─ hip_S(active) ─ thigh_S ─ elbow_S(passive) ─ lower_S ─ wheel_support(passive)┘
```

- `M = motor-side = inner branch`，`S = support-side = outer branch`。
- 每条轮足有 5 个运动刚体、6 个转动连接和 3 个独立控制量。
- 整机有 20 个运动刚体、24 个转动连接、4 个闭环和 12 个独立控制量。
- 两个 elbow 是被动转轴，wheel motor 是主动轮轴，wheel support 是被动同轴支承。

## 审核方法

逐项比较候选资产的 link list、joint list、active/passive 分类、M/S 分支、wheel axis、DOF 和闭环表达。标准 URDF 是树；真实闭环如何在 USD/PhysX 中恢复必须由候选资产自身证据说明。

## Reduced Simulation Baseline

当前官方训练资产采用每腿 `thigh → calf → foot/wheel` 的 2R + wheel reduced serial model。它与真实机构同为每腿 3 个控制量、整机 12 个控制量，但没有显式恢复双支链闭环。M2-G02 的 PASS 表示这项结构差异已被识别并冻结，不表示二者机械或动力学等价。
