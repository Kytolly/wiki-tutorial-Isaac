# M2-T02 机械拓扑

## Scope

把真实轮足的刚体、主动/被动关节和闭环关系形式化表达为符合仿真引擎规范的数字资产拓扑。

---

## 真实机构与数字双链拓扑

机器人整机包含 4 条腿，每条腿具备真实的闭环五杆机构。为兼顾标准机器人学描述（严格树拓扑）与物理引擎求解需求，工程采用 **内外双支链分离 + 显式闭环断开（Loop Cut）** 的拓扑抽象：

```text
Outer chain (外链 / 主驱动链):
base_link
  -> M1 (thigh_joint, 主动舵机)
  -> outer_upper (thigh_Link, 金属舵片大腿)
  -> P1 (calf_joint, 膝部铰接)
  -> outer_lower (calf_Link, 外部小腿)
  -> W1 (foot_joint, 轮电机轴)
  -> foot (foot_Link, 轮体组件)
       └─ W1_frame (fixed, 闭环参考系)

Inner chain (内链 / 闭环支承链):
base_link
  -> M2 (M2_joint, 内侧主动舵机)
  -> inner_upper (inner_upper_Link, 内侧金属大腿)
  -> P2 (P2_joint, 被动膝部铰接)
  -> inner_lower (inner_lower_Link, 内部小腿)
  -> W2_frame (fixed, 闭环断开点 loop cut)
```

---

## URDF 严格树状拓扑规则（Strict Tree Invariant）

标准 URDF 规范强制要求：
1. **单一根节点（Single Root）**：全机唯一根为 `base_link`，不存在浮动孤立构件。
2. **严格单父级（Single Parent）**：每个刚体 link 必须且仅能拥有一个 parent joint。
3. **不得制造多父节点**：严禁为了闭环让 `foot_Link` 同时成为 `outer_lower` 和 `inner_lower` 的子节点。
4. **显式 Loop-Cut**：内链在 $W_2$ 处切断，固定连接一个纯定位无质量的 `W2_frame`。

当前正式 URDF 资产 `stackforce_quadrupedal_wheeled_robot.urdf` 包含：
- **29 links**（1 base_link + 4 腿 $\times$ 7 个 link）；
- **28 joints**（4 腿 $\times$ 7 个 joint）；
- 通过 `scripts/validate_asset.py` 的严格无环断言检查。

## Isaac Sim / PhysX 闭环恢复机制

在 Isaac Sim 导入阶段，通过 `scripts/recover_closed_loops.py` 将闭环约束添加在物理引擎层：

1. **保留固定坐标系**：导入 URDF 时设定 `merge_fixed_joints=False`，确保 `W1_frame` 与 `W2_frame` 在 USD Stage 中完整存在。
2. **独立反算局部变换**：
   以 $W_2$ 世界坐标系为公共机械轴位姿 $T_{\text{world\_joint}}$，分别向两端刚体反求局部位姿：
   $$T_{\text{local0}} = (T_{\text{world\_inner\_lower}})^{-1} \cdot T_{\text{world\_joint}}$$
   $$T_{\text{local1}} = (T_{\text{world\_foot}})^{-1} \cdot T_{\text{world\_joint}}$$
   严禁简单复制局部位姿（两构件自身本体系旋转截然不同）。
3. **PhysX 转动副定义**：
   在 `closure_joints` 作用域下为每条腿创建 `PhysicsRevoluteJoint`：
   - `physics:body0` $\to$ `inner_lower_Link`
   - `physics:body1` $\to$ `foot_Link`
   - `physics:axis = "X"`
   - `physics:collisionEnabled = false`（避免自碰撞爆炸）
   - `physics:excludeFromArticulation = true`（保持主树形关节链的高性能多刚体解算，将闭环作为附加拉力约束求解）。
