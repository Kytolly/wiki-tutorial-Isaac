# M6-T01 部署流程

## Scope

规定策略进入真实机器人前的接口、保护和逐级测试流程。

## 同构接口

```text
Policy
  ↓ action / observation
SimRobotInterface  ↔  RealRobotInterface
  ↓                       ↓
Isaac Sim              IMU / actuator bus
```

Policy 不区分 PhysX 和真实机器人；两侧必须使用同一 joint order、单位、坐标、限幅和 observation/action 版本。

## 测试顺序

```text
sensor only
→ shadow inference（不发 action）
→ suspended robot
→ 10% action limit
→ 20% action limit
→ protection frame / soft pad
→ standing
→ balance
→ low-speed target motion
```

每一级都可立即停机并保留日志；任何方向、量程、NaN、超时或姿态异常都回退到上一级。

## 保护边界

硬件或独立 runtime 层负责 joint position/velocity/current limit、body tilt limit、communication timeout、policy timeout 和 emergency stop。策略不能绕过这些保护。
