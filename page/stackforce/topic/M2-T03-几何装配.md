## 四腿底盘对称性反射法则

FR（右前腿）为唯一经过物理测量与 Blender/Isaac 空间注册的主内链基准。FL（左前）、RL（左后）、RR（右后）严格通过底盘中心坐标 $C$ 的反射矩阵生成：

$$\begin{aligned}
\text{FR: } p' &= C + \text{diag}( 1,  1, 1) (p - C) \\
\text{FL: } p' &= C + \text{diag}(-1,  1, 1) (p - C) \\
\text{RL: } p' &= C + \text{diag}(-1, -1, 1) (p - C) \\
\text{RR: } p' &= C + \text{diag}( 1, -1, 1) (p - C)
\end{aligned}$$

### 单平面镜像的网格绕向反转（Face Winding Reversal）
- FL 与 RR 涉及单个坐标轴的反转（$\det = -1$），属于手性变换。
- 在提取二进制 STL 网格时，`build_asset.py` 严格对三角形面片顶点顺序进行颠倒（Face Winding Reversal），以确保外部法向量计算正确，避免渲染时出现面片反转或法线反向穿模。
- 严禁对 FL/RL/RR 独立人工拟合或搜寻铰链孔位。

## 三维装配约束不变量

1. **同轴而不重合**：$W_1$ 与 $W_2$ 沿公共机械轴 $\mathbf{a}$ 存在 $-44.950\text{ mm}$ 的轴向装配厚度，径向残差严格为零（$1.83 \times 10^{-17}\text{ m}$）。严禁强制将 $W_2$ 与 $W_1$ 坐标设为相同。
2. **解耦铰接点与渲染网格**：P2 铰链轴心是刚体动力学连接点；若出现网格贴合或穿模，只能调整 visual mesh 局部偏移，严禁移动机械铰链中心。
3. **Link Local 规范网格**：`build_asset.py` 自动导出 21 组以各 link 自身原点对齐的英文命名规范二进制 STL 网格，彻底消除嵌套变换与多重坐标系错位。
