# M2-T03 几何装配

## Scope

审核资产的尺寸、装配变换、mesh frame 和轮轴几何是否与实体和官方资料一致。

## 名义基线

| 几何 | 值 | 状态 |
|---|---:|---|
| `thigh_M` / `thigh_S` | 60 mm | SUPPORTED |
| `lower_M` / `lower_S` | 100 mm | SUPPORTED |
| 两 hip 二维投影间距 `L5` | 40 mm | SUPPORTED（仅投影） |
| Mini tire 直径 / 轴向宽 | 约 66.0 / 29.9 mm | SUPPORTED（仅候选 visual） |
| 整机长 / 宽 / 高 | 约 375 / 215 / 105–205 mm | SUPPORTED |

这些值不是 M1 实测 Ground Truth；M1 的测量结果优先。

## 三维约束

M/S 两个大腿根不是同一三维点。有效闭环必须同时满足：

1. 两支链 wheel endpoint 在腿平面投影一致。
2. `wheel_motor` 与 `wheel_support` 轴方向平行。
3. 两轴线最短距离为 0，即同一物理 wheel axis。

不能用 `p_M == p_S` 代替三维约束，也不能把 `L5` 直接写成三维 URDF origin。

## 坐标和 mesh frame

- `+X forward / +Y left / +Z up` 为 `ROBOT_BASE`。
- thigh/lower link origin 分别位于 hip/elbow axis。
- thigh/lower STL 主关节轴沿 raw `+Z`、杆长沿 raw `+X`，几何约定使用 `R_link_mesh = Rx(-90°)`。
- mesh frame 约定不等于 actuator 正方向，二者分别审核。

## 已否决候选

`±76.5 mm` half-body longitudinal translation 已被视觉验证否决，不得重新作为有效装配候选，详见 [[M2-reverse-engineering]]。
