# M4-T01 运动任务

## Scope

定义仿真 locomotion 任务、观测/动作合同、课程顺序和 `sf_quad` 的当前实现边界。

## 当前代码基线

`sf_quad` Direct 任务注册为 `Template-Sf-Quad-Direct-v0`。Direct 配置使用 `sf_robot.urdf`，声明 12 个动作、48 维 observation、仿真 `dt = 1/200`、`decimation = 4`，动作先转换为 joint position target。

Direct observation 当前由 root linear/angular velocity、projected gravity、3 维 command、12 维 joint position error、12 维 joint velocity 和 12 维 action 组成。实际运行结果尚未归档。

`manager_based/sf_quad` 当前场景仍引用 Isaac Lab Cartpole 配置，因此不能把它当作 StackForce Manager-Based 实现。

## 任务顺序

```text
Standing → Balance → Push recovery → Forward/Backward velocity
→ Yaw turning → Height control → Wheel → Legged → Wheel-leg hybrid → Terrain
```

第一项只做 Stand；每增加一个任务都固定训练配置、评测场景和指标。Actor 只能使用未来实机可获得的 observation，不得读取仿真专有真值。

## 动作选择

第一版优先：

```text
Policy → desired joint position → PD/actuator model
```

直接 torque policy 作为后续对照，不在没有 M3/M6 安全证据时作为默认部署路径。
