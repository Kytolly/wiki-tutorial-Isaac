# M2-T07 坐标约定

## Scope

冻结 simulation asset 的 base frame、link frame、joint axis、零位和正方向，并与 M1 标定建立逐项映射。

## 当前基线

- `ROBOT_BASE` 使用 `+X forward / +Y left / +Z up`。
- thigh link origin 位于 hip axis，lower link origin 位于 elbow axis。
- thigh/lower STL 主关节轴沿 raw `+Z`、杆长沿 raw `+X`；当前几何约定使用 `R_link_mesh = Rx(-90°)`。

Mesh rotation 只解释视觉几何如何放进 link frame，不自动决定 actuator 的正方向。joint axis 和 action sign 必须由 M1-G04 实机标定结果确认。

## 对齐表

每个关节记录：

```text
joint name
parent / child
joint origin
axis
q = 0 physical pose
q > 0 physical motion
M1 calibration version
asset version
```
