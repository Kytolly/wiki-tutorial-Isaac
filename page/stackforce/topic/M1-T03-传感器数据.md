| :--- | :--- | :--- | :--- | :--- | :--- |
| **机身姿态角** | MPU-6050 (I2C) | Roll, Pitch, Yaw [deg] | 175.3 Hz (mean 5.704 ms) | **AVAILABLE**（策略核心观测输入） | [`E-TEST-001#P02`](../../../docs/evidence/E-TEST-001-实机架空通信时序与固件超时停机测定.md) |
| **机身三轴角速度** | MPU-6050 (I2C) | Gyro X, Y, Z [deg/s] | 175.3 Hz (mean 5.704 ms) | **AVAILABLE**（策略自稳观测输入） | [`E-FW-001#P04`](../../../docs/evidence/E-FW-001-双足轮腿舵机标定固件项目.md) |

## 2. IMU 姿态解算与坐标系偏置基线（IMU Kinematic Baseline）

主控 S3 通过硬件 I2C 读取 MPU-6050 原始加速度计与陀螺仪寄存器，在固件中执行一阶互补滤波，其姿态角解析公式如下（[`E-FW-001#P04`](../../../docs/evidence/E-FW-001-双足轮腿舵机标定固件项目.md)）：

```cpp
pitch =  mpu6050.getAngleX() + pitch_off; // 初始偏置 pitch_off = 2
roll  = -mpu6050.getAngleY() + roll_off;  // 初始偏置 roll_off = -1
yaw   =  mpu6050.getAngleZ();
```

- **坐标系物理对应**：`roll` 表达式中显式增加了负号 `-mpu6050.getAngleY()`，表明传感器贴片物理坐标系与机器人本体 Base Frame 的 Y 轴方向相反。
- **角速度正方向**：
  - 机头向上仰视（Nose-up Pitching）$\rightarrow \text{GyroX} < 0$；
  - 机身向左侧倾（Left Tilt Rolling）$\rightarrow \text{GyroY} > 0$；
  - 俯视逆时针旋转（Top-view CCW Yawing）$\rightarrow \text{GyroZ} < 0$。

## 3. 手持只读动觉检验规程（Read-Only Kinesthetic Verification Matrix）

在整机执行器上电前，必须进行**手持只读动觉检验（只读不控制）**，通过物理晃动机器狗机身，验证串口监视器输出的反馈正负号与预期完全一致：

| 手工物理激励动作 | 理论预期变化 (Expected Sign) | 源码对应算法依据 | 实机串口验证标准 (Pass Criteria) |
| :--- | :--- | :--- | :--- |
| **手持机身向前俯角倾斜 10°** | $\Delta \text{Pitch} > 0$ | `pitch = getAngleX() + 2` | 监视器打印值数值增大 |
| **手持机身向后仰角倾斜 10°** | $\Delta \text{Pitch} < 0$ | `pitch = getAngleX() + 2` | 监视器打印值数值减小 |
| **手持机身向左侧倾翻 10°** | $\Delta \text{Roll} > 0$ | `roll = -getAngleY() - 1` | 监视器打印值数值增大 |
| **手持机身向右侧倾翻 10°** | $\Delta \text{Roll} < 0$ | `roll = -getAngleY() - 1` | 监视器打印值数值减小 |
| **悬空向前拨动后左驱动轮** | $\Delta \text{Vel}_{\text{RL}} > 0$ | `M0_Vel` 正转反馈 | 输出正向线速度/角速度 |
| **悬空向前拨动后右驱动轮** | $\Delta \text{Vel}_{\text{RR}} < 0$ | `M1_Vel` 镜像反转反馈 | 输出负向线速度/角速度（右侧镜像反转） |
