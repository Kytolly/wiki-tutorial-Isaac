# M1-T03 传感器数据

## Scope

为每个实机 observation 固定数据来源、单位、坐标系、正方向和更新方式。

## IMU

| 字段 | 源码表达 | 当前状态 |
|---|---|---|
| 姿态 | `getAngleX/Y/Z()` | deg；nose-up pitch<0、left tilt roll>0 |
| 角速度 | `getGyroX/Y/Z()` | deg/s；nose-up gyroX<0、CCW yaw gyroZ<0 |
| 加速度 | MPU6050 可提供，但当前主程序未直接用于整机控制 | CONFIRMED |
| update-call timing | mean 5.704 ms / 175.3 Hz；jitter 0.790 ms | HARDWARE MEASURED |

主程序的姿态变换为：

```cpp
pitch = mpu6050.getAngleX() + pitch_off;
roll  = -mpu6050.getAngleY() + roll_off;
yaw   = mpu6050.getAngleZ();
```

当前初始化偏置为 `pitch_off = 2`、`roll_off = -1`。以上 frame/sign 已由 nose-up、left-tilt 与 top-view CCW 实机动作注册。

## BLDC 反馈

`SF_BLDC_DATA` 包含 `Angle`、`ElecAngle`、`Vel`、`Uq`、`Ud`、`Iq`、`Id`。主程序明确使用 `M0_Vel` 和 `M1_Vel`；前轮速度回传代码目前被注释，不能假设 Device `0x01` 能收到前轮速度。

底层 API 注释给出 `getAnlge()` 为 rad、`getVelocity()` 注释为 rad、`getCurrent()` 为 mA，但整机输出单位和速度是否为 rad/s 仍需实机核实。

## 腿部反馈

当前 `SF_Servo` 只提供 PWM/angle command，没有位置、速度或电流读取 API。因此 Actor observation 不能默认依赖 8 个腿关节的真实 encoder。

## PPM

PPM 输入位于 GPIO40，共 8 通道，sync gap 3000 μs。源码注释中 CH1 用于左右转向、CH2 用于前后、CH3 用于腿高、CH4 用于 roll，其余通道用于速度或模式切换。
