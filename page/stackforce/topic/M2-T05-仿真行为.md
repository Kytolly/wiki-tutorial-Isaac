# M2-T05 仿真行为

## Scope

在 Isaac Sim 中运行候选资产并验证加载、刚体、关节、重力和接触行为。

## 验证顺序

1. visual load。
2. articulation root 和刚体数量。
3. joint motion 与 DOF。
4. gravity、default pose 和 reset。
5. collision/contact。
6. wheel rotation。
7. closed-loop stability。

## 当前证据

`sf_robot.usda` 在 Isaac Sim 6.0.1 中有 visual load PASS。当前没有足够证据将 articulation、physics、碰撞、关节运动或闭环稳定性标为 PASS。

## 记录格式

每次验证记录 Isaac Sim/Isaac Lab 版本、资产 commit、启动参数、无头或 GUI 模式、日志路径和结果。GUI 启动警告不能替代行为结果。
