## 1. 软件分层与适配器架构（Adapter Pattern）

为了使强化学习训练所得策略（RL Policy）能够零代码修改迁移至实体机器狗，系统必须在算法策略与底层硬件驱动之间建立统一的抽象层：

```text
                     RL Policy
                         │
                      action (12-dim)
                         │
                         ▼
                [ StackForceRobot API ]
                         │
           ┌─────────────┴─────────────┐
           ▼                           ▼
   Simulator Adapter             Real Adapter
   (Isaac Sim / PhysX)           (Serial / CAN / ESP32)
           │                           │
   UsdArticulation             CH340K / USB-UART
```

- **Policy 隔离原则**：强化学习上层逻辑严禁直接调用底层硬件通信接口（如 `can.send()`、`Serial2.write()`），只能通过 `StackForceRobot` 访问版本化的 Observation 与 Action。

## 2. 统一 Python Hardware API 骨架规范

```python
class StackForceRobot:
    """StackForce 轮足机器狗统一控制与观测接口"""

    def enable(self) -> bool:
        """硬件使能：拉高执行器使能脚，解除电机与舵机安全锁"""
        ...

    def disable(self) -> None:
        """硬件失能：断开电机驱动力矩，舵机释放刚度"""
        ...

    def emergency_stop(self) -> None:
        """急停：立即清零指令，触发底层固件硬件级超时断电"""
        ...

    def read_imu(self) -> dict:
        """读取机身 6-DOF 惯导数据：返回 roll, pitch, yaw [deg] 及角速度 [deg/s]"""
        ...

    def read_wheel_velocities(self) -> list:
        """读取后轮转速：返回 [RL_Wheel_Motor, RR_Wheel_Motor] 实时转速"""
        ...

    def get_observation(self) -> dict:
        """获取对齐 Isaac Lab 维度的标准观测张量"""
        return {
            "imu_angles": self.read_imu()["angles"],
            "imu_gyro": self.read_imu()["gyro"],
            "last_action": self.last_action,
        }

    def send_action(self, action: list) -> None:
        """
        发送 12 维动作向量（严格遵循 CANONICAL_ACTUATED_JOINTS 顺序）：
        前 8 维为腿舵机开环位置指令 [rad]，后 4 维为轮电机 Mode 4 力矩指令 [-100, 100]
        """
        # 必须先经过 Safety Layer 守卫拦截，方可进入硬件驱动
        safe_action = self.safety_layer.guard(action)
        self.adapter.write(safe_action)
```

## 3. 跨平台合同保证（Cross-Platform Contract）

1. **执行器数组顺序一致性**：
   - 必须严格遵循 `CANONICAL_ACTUATED_JOINTS` 数组（`FL -> FR -> RL -> RR`，腿部 `Outer -> Inner -> Wheel`）；
2. **Observation 同构性**：
   - 仿真适配器与真机适配器输出完全同构的张量字典，保证策略输入在 Sim 和 Real 间无量纲差异；
3. **安全拦截不可绕过**：
   - `send_action()` 在触发任何通信封包前，必须经过限幅、超时看门狗与 NaN 检测（详见 `[[T03-安全联锁]]`）。
