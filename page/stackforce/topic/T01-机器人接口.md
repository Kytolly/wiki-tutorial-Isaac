# T01 机器人接口

## Scope

定义仿真和实机共享的最小 Robot API，隔离策略与硬件驱动。

## API 形状

```python
class StackForceRobot:
    def enable(self): ...
    def disable(self): ...
    def emergency_stop(self): ...
    def get_observation(self): ...
    def send_action(self, action): ...
```

底层 adapter 负责 CAN、PCA9685、Serial2、IMU 和时间戳；Policy 只看到版本化 observation/action。

## 合同

- joint order 与 [[M1-T02-执行器映射]] 一致。
- 单位、坐标、符号和 shape 显式声明。
- `send_action` 在限幅、超时和 NaN 检查之后才可触达执行器。
- 仿真 adapter 和实机 adapter 对同一 action 返回同构 observation。
