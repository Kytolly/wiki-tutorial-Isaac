# M1-T01 硬件基线

## Scope

把官方工程源码能确认的硬件、控制器、总线和连接关系集中记录。源码事实不等于实体测量；没有证据的字段保持 `UNKNOWN`。

## 源码基线

| 项目 | 当前结论 | 状态 |
|---|---|---|
| 主控 | ESP32-S3 DevKitC-1，Device `0x01` 和 `0x02` | CONFIRMED |
| 软件平台 | Arduino / PlatformIO，`espressif32@6.6.0` | CONFIRMED |
| IMU | MPU6050，经 I2C 接入 | CONFIRMED |
| 腿部执行器 | 8 路 PCA9685 PWM 舵机，无源码反馈接口 | CONFIRMED |
| 轮部执行器 | 4 路 BLDC；主程序调用 `setModes(4, 4)` | CONFIRMED |
| I2C | SDA GPIO1、SCL GPIO2、400 kHz；PCA9685 地址 `0x40` | CONFIRMED |
| CAN/TWAI | TX GPIO35、RX GPIO41、1 Mbit/s、extended 29-bit | CONFIRMED |
| PPM | GPIO40，8 通道，sync gap 3000 μs | CONFIRMED |
| 调试串口 | UART 115200 | CONFIRMED |
| BLDC 串口 | 两块控制器均使用 `Serial2` | CONFIRMED |

| 实体安装位置、电池和具体型号 | 当前资料不足 | UNKNOWN |

## 数据流

```text
PPM(GPIO40) → Device 0x01
Device 0x01 → I2C → PCA9685(8 舵机) + MPU6050
Device 0x01 → Serial2 → 后轮双路 BLDC
Device 0x01 → CAN 1 Mbit/s → Device 0x02 → Serial2 → 前轮双路 BLDC
```

Device `0x01` 负责 PPM、IMU、8 路舵机、后轮 BLDC、姿态稳定、逆运动学和前轮 CAN 目标；Device `0x02` 接收 8 字节 CAN 命令并驱动前轮双路 BLDC。
