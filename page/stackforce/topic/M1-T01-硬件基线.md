## 2. 物理总线拓扑与引脚分配基线（Bus Topology & Pinout）

```text
[PPM 遥控器] ---> GPIO40 ---> [Device 0x01 (Stack B)]
                               │
                               ├--- I2C (SDA=GPIO1, SCL=GPIO2, 400kHz) ---> PCA9685 (8 Servos) + MPU6050
                               ├--- Serial2 ---> S1 Driver ---> 双路后轮 BLDC (RL/RR)
                               │
                               └=== TWAI/CAN (TX=GPIO35, RX=GPIO41, 1Mbps) ===> [Device 0x02 (Stack A)]
                                                                                  │
                                                                                  └--- Serial2 ---> S1 Driver ---> 双路前轮 BLDC (FL/FR)
```

### 物理总线参数真值表
1. **I2C / Wire 总线**：
   - **引脚配置**：SDA = `GPIO 1`, SCL = `GPIO 2`，时钟速率 `400 kHz`（`E-HW-001#P05`）。
   - **挂载外设**：`PCA9685PW` 12-bit PWM 发生器（I2C 地址 `0x40`）、`MPU-6050` 六轴惯导（`E-HW-002#P01-P02`）。
2. **TWAI / CAN 差分总线**：
   - **引脚配置**：TX = `GPIO 35`, RX = `GPIO 41`，通信速率 `1 Mbit/s`，Extended 29-bit 帧格式（`E-HW-004#P01`）。
   - **终端匹配**：Stack A 与 Stack B 板载 `120Ω` 终端电阻，确保高频通信无回波反射（`E-HW-004#P03`）。
3. **PPM 接收机接口**：
   - **引脚配置**：信号接入 `GPIO 40`，8 通道脉宽调制输入，同步脉冲间隔（Sync Gap）为 `3000 μs`（`E-FW-003#P02`）。
4. **BLDC Serial2 通信**：
   - **软件接口**：主控 S3 通过板级 UART2（`Serial2`）连接 S1 电机控制核心；协议细节由预编译静态库 `libSF_Motor.a` 封装（`E-FW-002#P05`）。

## 3. 全局未决证据债务矩阵（U01~U24 Evidence Debts）

依据全周期项目治理元数据（`_meta/omissions.yaml`），当前机器狗在硬件吃透与地面部署之间记录有 24 项系统性未决债务，分为三大等级：

### Group A: 建模与强化学习阻塞级债务（High Priority）
- **U01 [RESOLVED]**：舵机关节语义绑定。已通过 `E-SIM-001#P01` 与 `canonical-component-topology.md` 确定为 `{LEG}_{BRANCH}_Hip_Joint` 与 `{LEG}_{BRANCH}_Knee_Joint`。
- **U02 [OPEN]**：舵机绝对物理机械零位。出厂 `servo_off`（-8°~+8°，见 `E-CAL-001#P01`）仅为初调偏移，非绝对机构零位。
- **U03 [OPEN / BLOCKED]**：舵机物理正方向与 URDF 轴向对齐。受限于 `ch7` 硬件异常，暂阻断实测（需无负载小步阶跃验证）。
- **U04 [OPEN]**：各连杆机械限位极限。API 0~300° 范围非实际机械运动范围。
- **U05 [RESOLVED]**：腿部关节编码器反馈。确证无编码器反馈，仅能采用开环 PWM 驱动（`E-FW-001#P03`）。
- **U06 [RESOLVED]**：IMU 相对安装旋转。通过 `E-FW-001#P04` 确证 `pitch=AngleX+2`, `roll=-AngleY-1`。
- **U07 [RESOLVED]**：IMU 更新率。实测确认为 175.3 Hz，Jitter 为 0.790 ms（`E-TEST-001#P02`）。
- **U08 [RESOLVED]**：前轮 M0/M1 映射。确证 CAN target1=右前（`FR_Wheel_Motor`），target2=左前（`FL_Wheel_Motor`）（`E-FW-004#P03`）。
- **U09 [OPEN]**：四轮速度正负极性与反馈符号。后轮确认为 +1/-1，前轮待实地滚转验证。
- **U10 [OPEN]**：BLDC Mode 4 力矩标称比例。协议定点数 `[-100, 100]` 与标准 SI 单位（$N\cdot m$）换算待台架标定。

### Group B: 控制与通信性能债务（Medium Priority）
- **U11 [OPEN]**：主循环 `loop()` 调度抖动。无 RTOS 固定硬件中断定时器调度。
- **U12 [RESOLVED]**：CAN 差分总线帧率。1 Mbit/s 满足实时通讯要求（`E-TEST-001#P01`）。
- **U13 [DEFERRED]**：Serial2 内部闭源通信封包。封存于 `SF_BLDC` 库边界内。
- **U14~U16 [RESOLVED/OPEN]**：端到端延迟上界测量在 0.5 s 内（`E-TEST-001#P01`）。
- **U17 [RESOLVED]**：看门狗超时停机。确证固件在通信中断后 501.5~502.5 ms 内拉低使能断电（`E-TEST-001#P03`）。

### Group C: 动力学、质量与接触属性（Deferred for Kinematic-First）
- **U18~U24 [DEFERRED]**：整机实称质量（当前采用 URDF 标称 1.3525 kg）、各连杆转动惯量、关节摩擦与阻尼系数、轮地接触摩擦因数。
