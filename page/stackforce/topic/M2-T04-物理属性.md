# M2-T04 物理属性

## Scope

为数字资产补齐质量、质心、惯量、碰撞、关节限位、驱动和闭环所需的物理表达。

## 审核字段

| 字段 | 当前状态 |
|---|---|
| reduced asset mass | 1.352539 kg；URDF_DEFINED / PASS |
| COM / inertia | 全刚体完备、对称正定、主惯量合法 / PASS |
| collision geometry | URDF → USD 保存、runtime contact/rolling / PASS |
| 真实 joint limits | M1_REQUIRED |
| damping / friction | M1_REQUIRED 或 M3 标定 |
| servo / wheel drive | 仿真 actuator coverage PASS；真实响应待 M3 |
| closed-loop representation | reduced serial model，无显式真实闭环 |
| articulation root | runtime integration PASS |

## 约束

- `UNKNOWN` 不得写成 0。
- CAD/STL 推导值只能作为初值，不能冒充实测质量。
- 若按质量比例校正 CAD 惯量，应记录公式和来源：`I_corrected ≈ I_CAD × m_real / m_CAD`。
- 旧的“wheel_support 断环 + USD/PhysX 恢复”只能作为历史设计候选，不能默认套用。
