# M2-T04 物理属性

## Scope

为数字资产补齐质量、质心、惯量、碰撞、关节限位、驱动和闭环所需的物理表达。

## 审核字段

| 字段 | 当前状态 |
|---|---|
| 整机/各腿/轮/body mass | M1_REQUIRED |
| COM / inertia | M1_REQUIRED；CAD 值需实测校正 |
| collision geometry | 待审核 |
| 真实 joint limits | M1_REQUIRED |
| damping / friction | M1_REQUIRED 或 M3 标定 |
| servo / wheel drive | 待审核；腿为 PWM position，轮为 `TORQUE_MODE` |
| closed-loop representation | 待审核 |
| articulation root | 待审核 |

## 约束

- `UNKNOWN` 不得写成 0。
- CAD/STL 推导值只能作为初值，不能冒充实测质量。
- 若按质量比例校正 CAD 惯量，应记录公式和来源：`I_corrected ≈ I_CAD × m_real / m_CAD`。
- 旧的“wheel_support 断环 + USD/PhysX 恢复”只能作为历史设计候选，不能默认套用。
