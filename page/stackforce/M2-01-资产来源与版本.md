## 🎯 为什么需要这个？

先搞清楚"这个资产从哪来、怎么生成、有哪些版本"，否则后面的拓扑/几何/物理审核都没有锚点。

## 审核对象

| 来源 | 内容 | 状态 |
|------|------|------|
| `Stackforce-simready-111-isaac-lab` | 含 `sf_robot.usda` 的 SimReady 包 | CANDIDATE_ASSET / UNDER_AUDIT |
| `quadrupedal-wheeled-robot` | 官方 STL + PlatformIO 课程代码 | CONFIRMED（官方） |
| SimReady package | USD 组合 / source URDF / meshes | 待审核 |
| `sf_robot` | 候选机器人资产 | 待审核 |
| Mini URDF（bipedal） | 仅格式/轮视觉参考 | SUPERSEDED（不可作四轮足 tree） |

## 需要确认的清单

- `sf_robot.usda` 的 README / source URDF / meshes / USD composition
- Isaac Lab config（是否自带）
- package version / commit / 生成来源（谁、用什么工具生成的）
- 资产生成链：官方 CAD/STL → URDF → USD → SimReady 的哪条路径

## Source of Truth 优先级

1. 官方/SimReady asset provenance
2. 实体机器人
3. 官方安装/接线/调试资料
4. 官方 IK / code
5. 官方 STL
6. 独立 mechanical_model / geometry baseline

> 在 provenance 审核通过前，不把 sf_robot 当作 M3/M4 的 baseline。
