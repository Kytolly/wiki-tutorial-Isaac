# M2-03-几何审核

> 本页属于：stackforce 机器狗实战（M2 资产检查）
> 前置知识：[[M2-02-机械结构审核]]
> 预计阅读时间：20 分钟

## 🎯 为什么需要这个？

机械拓扑对了之后，审核几何：尺寸、装配、mesh 朝向是否与实体/STL/官方 IK 一致。

## 名义几何（已确认基线）

| 几何 | 值 | 状态 |
|------|----|------|
| thigh_M / thigh_S | 60 mm | SUPPORTED |
| lower_M / lower_S | 100 mm | SUPPORTED |
| L5（两 hip 二维投影间距） | 40 mm | SUPPORTED（仅二维投影，非三维 origin） |
| 整机长 / 宽 / 高 | ≈375 / 215 / 105–205 mm | SUPPORTED |
| 整机重量 | ≈1.3 kg | SUPPORTED（仅 Dynamics 检查） |

## 审核要点

- chassis、FL/FR/RL/RR 的几何
- M/S 两支链的空间 offset（真实机构**不是同一平面**，不能压成二维）
- front/rear 安装朝向
- wheel 几何与 front/rear 安装
- 与实体照片 / 官方 STL / 官方 IK 对照

## Lessons Learned（必须遵守）

- **STL AABB / STL export frame 不能直接当作 assembly datum**（不同 STL 导出姿态不统一）。
- `L5=40mm` 只是二维 IK 投影参数，不能直接当三维 URDF origin。
- Mini wheel/tire geometry 仅可作 wheel visual 参考/候选；四轮足有自己的轮固定、轮毂、电机和支承结构。

## 已知 REJECTED 值

- `±76.5 mm`（half-body longitudinal translation 候选）已被 FreeCAD 视觉验证否决，**不得再作为有效装配候选**（见 [[M2-reverse-engineering]]）。
