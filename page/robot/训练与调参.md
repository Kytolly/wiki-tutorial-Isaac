## 🎯 为什么需要这个？

任务定义好之后，就要跑训练并调参。本页给出一套"先跑通、再调好"的流程和常见参数。

## 💡 一个类比

训练调参 = 练车：先低速跑通路线，再逐步提速、加难度（curriculum）。

## 核心概念

| 概念 | 说明 |
|------|------|
| **num_envs** | 并行环境数（显存允许则多开） |
| **headless** | 不渲染画面，省资源 |
| **curriculum** | 由易到难：平地 → 坡道 → 台阶/扰动 |
| **PPO 超参** | lr、clip、batch、迭代步数 |

## 快速上手

```bash
# 先小规模跑通
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py \
  --task Template-StackForce-v0 --num_envs 512 --headless

# 显存不足就减 num_envs；想观察就去掉 --headless
```

## 调参顺序（建议）

1. **奖励权重**：先让 reward 上升，再看行为是否合理。
2. **动作平滑**：调 smooth 惩罚，减少真机抖动。
3. **域随机化**：逐步加质量/摩擦/延迟/观测噪声。
4. **curriculum**：平地稳定后再加地形。
5. **观察曲线**：episode 长度、平均 reward 持续上升即健康。

## 本章小结

- 先小规模 headless 跑通，再扩 num_envs。
- 调参顺序：奖励 → 平滑 → 随机化 → curriculum。
- 观察 reward 与 episode 长度判断健康度。
