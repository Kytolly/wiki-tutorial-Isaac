## 🎯 为什么需要这一页？

## 💡 L0 全景回顾

```text
Isaac Sim(物理世界) + Isaac Lab(训练框架)
        │
        ├─ 是什么？  → L0-Isaac-Sim是什么 / L0-Isaac-Lab是什么
        ├─ 装环境？  → L0-安装与环境配置
        ├─ 跑得通？  → L0-运行第一个Demo
        └─ 下一步？  → 本页 → L1
```

你此刻应具备的能力：

- 说清 Isaac Sim（物理仿真器）和 Isaac Lab（RL 训练框架）的分工。
- 知道关键术语：物理仿真器、数字孪生、USD、PhysX、RL、环境、策略、向量化。
- 装好 Python 3.11 + PyTorch(cu128) + isaacsim + Isaac Lab。
- 跑通 `list_envs.py`、`train.py`、`play.py` 一条龙。

## 🐍 L1 预览：为什么是这个顺序？

| 顺序 | 页面 | 解决什么问题 |
|------|------|-------------|
| 1 | [[L1-强化学习核心概念]] | 先补足"策略到底怎么被训练出来的"理论直觉 |
| 2 | [[L1-Isaac-Lab项目结构与训练流程]] | 看懂 Isaac Lab 源码目录、train/play 背后发生了什么 |
