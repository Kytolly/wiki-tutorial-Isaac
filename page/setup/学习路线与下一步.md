## 🎯 为什么需要这一页？

学完 setup，你已经"看得懂、装得上、跑得通"。但碎片化知识容易散，本页帮你**把 setup 串成一张图，并告诉你 L1 要学什么、为什么按这个顺序学**。

## 💡 setup 全景回顾

```text
Isaac Sim(物理世界) + Isaac Lab(训练框架)
        │
        ├─ 是什么？  → Isaac-Sim是什么 / Isaac-Lab是什么 / Isaac Sim架构与核心概念 / 协作全景
        ├─ 装环境？  → 安装与环境配置
        ├─ 跑得通？  → 运行第一个Demo
        ├─ 改世界？  → USD场景入门 / 物理仿真设置
        └─ 下一步？  → 本页 → train
```

你此刻应具备的能力：

- 说清 Isaac Sim（物理仿真器）和 Isaac Lab（RL 训练框架）的分工。
- 知道关键术语：物理仿真器、数字孪生、USD、PhysX、RL、环境、策略、向量化。
- 装好 Python 3.11 + PyTorch(cu128) + isaacsim + Isaac Lab。
- 跑通 `list_envs.py`、`train.py`、`play.py` 一条龙。

## 🐍 train 预览：为什么是这个顺序？

| 顺序 | 页面 | 解决什么问题 |
|------|------|-------------|
| 1 | [[强化学习核心概念]] | 先补足"策略到底怎么被训练出来的"理论直觉 |
| 2 | [[Isaac-Lab项目结构与训练流程]] | 看懂 Isaac Lab 源码目录、train/play 背后发生了什么 |
| 3 | [[第一个训练任务]] | 用 `./isaaclab.sh --new` 生成自己的项目并跑训练 |

这个顺序是"**先懂原理 → 再看结构 → 再动手自建**"，避免一上来就陷进源码细节。

## 🚀 build 预览：train 之后学什么？

| 顺序 | 页面 | 解决什么问题 |
|------|------|-------------|
| 1 | [[Direct环境类深入]] | 看懂 Direct 环境生命周期，模板不再是黑盒 |
